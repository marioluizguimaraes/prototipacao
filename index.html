bloco 05 · por que gerar imagem

Código monta com peças, imagem gera pixels

Agente de código

Desenha escrevendo código

Toda tela é feita de peças: div, gradiente, SVG, fonte, ícone pronto. Só aparece o que dá para descrever com elas.

<svg>
  <ellipse/> // corpo
  <polygon/> // bico
  <circle/>  // janela
</svg>
×
Gerador de imagem · ChatGPT

Gera os pixels direto

Parte de texto e referência e entrega a aparência pronta. Luz, textura, volume 3D e vidro saem de primeira.

o limite do código não é inteligência, é a forma de representar.

erros comuns

Quando a tela foge da identidade

sintomacorreção
01

Deriva visual

Cores e espaçamentos mudam a cada tela.

Reenvie a tela aprovada em todo prompt.
02

Texto inventado

Lorem ipsum ou palavras sem sentido.

Escreva no prompt o conteúdo real da tela.
03

Componente diferente

Um card ou botão que não existe na tela aprovada.

Nomeie: “use os mesmos cards da tela Início”.
04

Erro que se repete

O mesmo detalhe errado volta toda rodada.

Reescreva a restrição de forma explícita.
